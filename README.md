# Kripto Para Takip Uygulaması

Bu proje, kripto para birimlerini takip etmenizi sağlayan modern bir web uygulamasıdır.

## Özellikler

- Kripto para listesi görüntüleme
- Detaylı kripto para bilgileri
- Fiyat grafikleri
- Favori kripto paraları kaydetme
- Fiyat alarmları
- Responsive tasarım

## Teknolojiler

- React.js
- TypeScript
- Tailwind CSS
- CoinGecko API
- Chart.js

## Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/kullaniciadi/crypto-app.git
```

2. Proje dizinine gidin:
```bash
cd crypto-app
```

3. Bağımlılıkları yükleyin:
```bash
npm install
```

4. Uygulamayı başlatın:
```bash
npm start
```

## Kullanım

Uygulama http://localhost:3000 adresinde çalışacaktır.
